# Обвес оружия: голографический прицел для MX16A4 (KINEMATION FPS)

Клавиша **M** открывает меню: слева 3D-превью оружия в руках (крутится само, можно вращать мышью),
справа — выбор обвеса: **Без обвеса / Голографический прицел**. Повторное **M** или **Esc** закрывает.

## Файлы

| Скрипт | Назначение |
|---|---|
| `WeaponAttachmentSystem.cs` | вешается на оружие, ставит/снимает прицел, переносит Aim Point |
| `WeaponCustomizationMenu.cs` | меню по клавише M (UI строится кодом) |
| `WeaponPreviewRenderer.cs` | 3D-иконка оружия через RenderTexture |
| `PreviewDragHandler.cs` | вращение превью мышью |
| `VoxelHoloSight.cs` | воксельный голографический прицел (EOTech) под стиль и текстуру оружия |
| `VoxelSightMarker.cs` | служебная метка установленного обвеса |

Работает и со старым Input Manager, и с новым Input System (KINEMATION 4 использует новый).
Подходит для Built-in и URP.

## Быстрый старт (без настройки)

1. Скачайте файлы: на GitHub откройте репозиторий, переключитесь на ветку `claude/zealous-keller-y9gp5r`,
   **Code → Download ZIP**.
2. Скопируйте папку `Assets/WeaponCustomization` в `E:\Games\Menxx_Unity\Assets\`.
3. Дождитесь, пока Unity скомпилирует скрипты: в Console **не должно быть красных ошибок**
   (при любой ошибке компиляции не работает ни один скрипт проекта).
4. Play → возьмите MX16A4 в руки → кликните в окно Game → **M**.

Меню создаётся само, а оружие ищется по имени (`MX16`) и настраивается автоматически.
В Console должны появиться строки `[WeaponCustomization] ...`. Ручная настройка ниже нужна только для
точной подгонки.

## Ручная установка

1. Скопируйте папку `Assets/WeaponCustomization` в `E:\Games\Menxx_Unity\Assets\`.
2. **Точка крепления.** Откройте префаб MX16A4 и найдите верхнюю планку Picatinny. Создайте на ней пустой
   дочерний объект `SightMount`: ось **Z** вдоль ствола (вперёд), ось **Y** вверх, позиция — на поверхности
   планки, примерно над серединой ствольной коробки.
3. **Компонент на оружие.** Добавьте на корень префаба MX16A4 `WeaponAttachmentSystem`:
   - `Weapon Name` = `MX16A4`
   - `Aim Point` — трансформ точки прицеливания, который использует KINEMATION
     (в демо это дочерний объект оружия `AimPoint`/`Aim Point`, он указан в компоненте оружия);
   - `Slots[0]`: `Slot Name` = `Прицел`, `Mount Point` = `SightMount`;
     `Hide When Attached` — механический целик/мушка, если они мешают (необязательно);
   - `Options[0]`: `Display Name` = `Голографический прицел`. `Prefab` можно оставить пустым — тогда прицел
     будет сгенерирован (`Use Procedural Holo Sight`). Если есть своя модель (EOTech и т.п.) — перетащите её в
     `Prefab` и добавьте в модель пустой дочерний объект **`AimPoint`** в центре сетки, ось Z — вперёд.
   - `Default Option` = `-1` (без прицела при старте) или `0` (прицел сразу установлен).
4. **Меню.** На любой объект сцены (например, на игрока) добавьте `WeaponCustomizationMenu`:
   - `Weapon` — MX16A4 (можно оставить пустым: возьмётся активное оружие в руках);
   - `Disable While Open` — перетащите контроллер игрока KINEMATION (`FPSController`) и `PlayerInput`,
     чтобы при открытом меню игрок не стрелял и не крутил камеру;
   - `Preview Layer` — свободный слой (по умолчанию 31).
5. Play → **M**.

## Прицеливание через голограф

После установки прицела `Aim Point` оружия переносится в точку `AimPoint` прицела, при снятии — возвращается
на место. Если ваша версия KINEMATION запоминает точку прицеливания только при доставании оружия,
подпишитесь на событие `On Attachment Changed` и вызовите там обновление прицеливания в своём контроллере
(или просто переключите оружие туда-обратно).

## Подгонка

- Прицел висит в воздухе или утоплен — поправьте `Local Position` в варианте обвеса или сам `SightMount`.
- Прицел развёрнут не туда — у вашей модели ствол смотрит не по +Z: задайте `Local Euler Angles`
  (например, `0, 90, 0` или `0, -90, 0`).
- Превью пустое — проверьте, что `Preview Layer` больше нигде не используется.

## Воксельный прицел

Если `Prefab` не назначен, прицел собирается из вокселей (≈11×13×15) в один меш с палитровой текстурой:
- размер вокселя определяется по мешу оружия (нужен Read/Write у модели; иначе — по длине оружия,
  либо задайте `Weapon Voxel Size` вручную), воксель прицела — делитель вокселя оружия (1:1, 1:2…);
- цвета корпуса и металла снимаются с текстуры оружия, шейдер — копия материала оружия;
- сетка прицела пиксельная, красная, с рисками, как у EOTech.

Шаг подгонки стрелками = один воксель прицела, Shift — 1 мм.

## Стиль меню

Меню оформлено под HUD: тонкие линии и уголки цвета перекрестия, полупрозрачный фон, виньетка.
Цвет меняется полем `Accent Color` у `WeaponCustomizationMenu`, шрифт — полем `Custom Font`.

При обновлении замените папку `WeaponCustomization` целиком (старый `ProceduralHoloSight.cs` больше не нужен).
